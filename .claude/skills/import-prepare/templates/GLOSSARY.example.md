# Gloomhaven icon tokens (MANDATORY, overrides TRANSCRIBE.md rule 2 for these icons)

The rulebook's own icon reference (rulebook p.52) LABELS every icon below, so
for these icons the token carries the book's label. Use EXACTLY these strings,
character for character, every time the icon appears inline (in prose, card
illustrations, examples, tables). Numbers that follow an icon stay as digits
after the token: "[Move icon] 3", "[Attack icon] 2".

If the printed WORD is also there ("Move 3" with the boot icon), write both, in
printed order: "Move [Move icon] 3" / "[Move icon] Move 3". Never replace a
printed word with a token.

## General icons (look -> token)
- black upward chevron ............................... [Initiative icon]
- black winged boot .................................. [Move icon]
- boot with curved arrow arcing over ................. [Jump icon]
- black spread wings ................................. [Fly icon]
- black wand/sword with burst/sparkle ................ [Attack icon]
- black bow and arrow ................................ [Range icon]
- solid RED hexagon (area-attack diagrams) ........... [red attack hex]
- solid GREY hexagon (area-attack diagrams) .......... [grey player hex]
- black bullseye target .............................. [Target icon]
- card with infinity sign + red arrow ................ [Persistent Bonus icon]
- card with circular arrow + red arrow ............... [Round Bonus icon]
- black shield ....................................... [Shield icon]
- black clenched fist ................................ [Retaliate icon]
- black droplet ...................................... [Heal icon]
- pile with up arrow ................................. [Loot icon]
- black 8-pointed starburst .......................... [XP icon]
- empty white circle with notch (use slot) ........... [Use Slot icon]
- circle slot containing a starburst ................. [Use Slot Gain XP icon]
- card with red X .................................... [Lost icon]
- card with red curved down arrow (item) ............. [Spend Item icon]
- crossed-out card stack (red X over stack) .......... [Cannot Recover icon]
- card with red check mark ........................... [Recover Ability icon]
- card with red curved arrow back up (item) .......... [Refresh Item icon]
- card showing red "-1" .............................. [-1 Attack Modifier icon]
- black crown ........................................ [Level icon]
- two circular arrows ................................ [Shuffle Deck icon]
- torn card .......................................... [Remove from Game icon]
- card on top of a stack ............................. [Return to Deck icon]

## Not icons (structural - keep as before)
- lettered callout markers on diagrams: "[callout a]", "[callout b]" ...
- monster-key standee circles: describe in a caption ("[Caption: black circle - No Monster]")
- card / board / map art: "[Card illustration: ...]", "[Diagram: ...]" with every
  rule-bearing printed label/number in it.

Any OTHER pictorial icon not in this list: fall back to TRANSCRIBE.md rule 2
(neutral look description, e.g. "[blue diamond with white star]"), use it
identically everywhere, and LIST it in your report.
